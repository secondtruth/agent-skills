# Game conception skill

## Decision

Build an original `game-conception` skill in the thinking plugin, composing with the existing brainstorming skill. The requested capability combines playful PC/console ideation, warm/cold articulation of atmosphere, and translating that atmosphere into player agency. Keep creative prompts and the optional concept brief in separate references.

The skills CLI search encountered network failure. No external skill content was imported. The bounded search does not establish that no suitable skill exists. Building directly fits the requested collaboration style and reuses the user's existing brainstorming method.

## Review scenarios

Desk review of the instructions, without claiming independent behavioral execution:

- A vague “quiet, eerie train journey” starts with contrasting playable scenes and warm/cold feedback.
- “Give me three console pitches now” produces short deliverables with assumptions rather than imposing an interview.
- “The atmosphere is right, but I have no mechanics” routes to the mood-board move and a minute of player action.
- “Make the idea feasible for a small team” preserves the defining interaction while reducing breadth and identifying an experiment.
- An engine debugging request falls outside the discovery description.
