# Tradition Families

This file defines which traditions belong to which family when a user invokes a family-level activation (e.g. "feminist perspective", "ecological perspective"). Some traditions belong to multiple families – this is intended and reflects genuine overlap.

## Family: Feminism

When user invokes: "feminist perspective", "feminist analysis", "feminist take", "Frauenperspektive", "feministische Sicht"

Traditions to load:
- `intersectional-feminism.md`
- `materialist-feminism.md`
- `liberal-feminism.md`
- `ecofeminism.md`

Note: These four schools are in active disagreement with each other on many questions – the synthesis should make those disagreements visible rather than presenting a smoothed-over consensus.

## Family: Ecology

When user invokes: "ecological perspective", "ökologische Sicht", "environmental analysis"

Traditions to load:
- `deep-ecology.md`
- `social-ecology.md`
- `ecofeminism.md`
- `degrowth-economics.md`
- `ecomodernism.md`

Note: Includes ecomodernism as the strongest internal critic of the other four. A family-level ecology analysis without it would be one-sided.

## Family: Ethics

When user invokes: "ethical analysis", "from an ethical standpoint", "moral perspective", "ethische Perspektive"

Traditions to load:
- `virtue-ethics.md`
- `deontological-ethics.md`
- `consequentialism.md`

Note: The three classical ethical traditions. They will give materially different verdicts on most non-trivial questions – that disagreement is the analysis.

## Family: Critical-Leftist

When user invokes: "critical theory", "leftist critique", "marxistische Sicht", "kritische Theorie"

Traditions to load:
- `critical-theory.md`
- `marxist-critique.md`
- `materialist-feminism.md`

## Family: Decolonial

When user invokes: "decolonial perspective", "postcolonial analysis", "Global South perspective"

Traditions to load:
- `decolonial-critique.md`
- `post-colonial.md`
- `ecofeminism.md` (the decolonial-ecofeminist current specifically)

## Family: Liberal

When user invokes: "liberal perspective", "liberal critique", "Enlightenment view"

Traditions to load:
- `liberal-feminism.md`
- `ecomodernism.md`
- (no standalone "classical liberalism" file – the liberal axioms are visible through these applied schools)

## Cross-cutting note

When invoking multiple families, traditions that appear in more than one family should be applied **once**, in the family where they fit most strongly for the topic at hand. The user does not need to see the same `ecofeminism.md` analysis under both "Feminism" and "Ecology" – pick the framing closer to the topic and note the dual membership.
