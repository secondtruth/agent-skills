# Temporal Shifts

## What this lens sees

How the situation looks different across time horizons – immediate, medium, long, and historical. Most analysis defaults to the time horizon of the participants' attention span; this lens stretches it deliberately.

## Key questions

- What does this look like in five years? In fifty?
- What does the historical trajectory leading to this moment tell us? What pattern is this an instance of?
- Which effects are reversible and which are not? Where are we at risk of foreclosing options?
- What is being discounted because it is far away in time? (Future costs, deferred benefits, accumulated debts.)
- If we ran this decision forward repeatedly, where does the cumulative effect end up?
- What was the situation before this practice existed? What problem was it created to solve, and does the problem still exist in its original form?

## Characteristic moves

1. **Stretch forward**: project the situation 1y / 5y / 25y. Identify which trends are present in the data now and which require assumptions.
2. **Stretch backward**: find the previous instance of this kind of decision in history (or in the user's own past). What happened?
3. **Mark irreversibility**: which choices, if wrong, cannot be undone? These deserve more analysis than reversible ones.
4. **Test discount rate**: would the analysis change if future effects were weighted equally to current ones?

## Known blind spots

This lens is speculative when stretched far. It can produce confident-sounding forecasts about deeply uncertain futures – treat outputs as scenarios, not predictions. It also assumes the *kind of thing* under analysis stays roughly the same over the horizon, which is often false (technological discontinuities, regime changes). Useful as a discipline against present-bias, not as a forecasting tool.

## Output format

A short paragraph per horizon (now / 5y / 25y / historical), plus a clearly marked **Irreversibility check** noting which present choices cannot be undone later.
