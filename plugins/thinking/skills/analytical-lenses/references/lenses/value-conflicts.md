# Value Conflicts

## What this lens sees

Where the situation appears to be a question of fact or efficiency but is actually a question of competing values being treated as if they were one. Most "disagreement" about decisions is value-conflict misdescribed as factual dispute.

## Key questions

- Which values are visibly at stake? Name them concretely (safety, freedom, fairness, efficiency, dignity, community, autonomy, sustainability, etc.).
- Which values are implicit – treated as background assumptions that "everyone agrees on"?
- Where are values in tension with each other in this situation? (Almost always there is at least one tension; if there isn't, the situation is either trivial or you have missed something.)
- Whose values are being centered? Whose are being treated as obstacles, special interests, or noise?
- Are tradeoffs being acknowledged or being papered over with "win-win" language?

## Characteristic moves

1. **Name the values** explicitly. Vague invocations ("we want what's best") hide the conflicts.
2. **Identify the tradeoff axis**. What is being sacrificed for what?
3. **Distinguish disagreement about facts from disagreement about values**. Disagreement about facts is resolvable with evidence; disagreement about values is resolvable only by deliberation or compromise.
4. **Resist false harmony**. If two values are in tension, say so – do not produce a phrasing that pretends they are not.

## Known blind spots

This lens can encourage endless value-clarification at the expense of action. Sometimes values are in tension and the answer is to choose anyway. Also: it does not tell you *which* values should win. That requires a normative framework (the `critical-traditions` skill, when it is among your available skills, provides several; pick deliberately rather than by default).

## Output format

A short paragraph naming the values at stake, followed by a clearly stated tension or set of tensions. End with: "*This tension cannot be dissolved analytically – it requires a value commitment*", if that is the case.
